\# 俄语电商标题优化完整规则库

\## 模块1：通用语法\&文本清洗规则

1\. 删除重复名词（例：лопасть, лопасть лопасти → лопасти）；

2\. 中式俄语错误词汇替换黑名单：

| 错误原文 | 标准替换词 | 使用场景 |

| ---- | ---- | ---- |

| плесень | форма | 食品模具、米饭成型器 |

| накрытие | покрывало | 防尘罩、沙池盖、遮盖布 |

| моп | швабра | 清洁拖把、扫地机拖布 |

| утолщенная нержавеющая сталь | утолщенная нержавейка | 不锈钢厨具、茶壶 |

3\. 统一语序结构：产品主体 + 材质/适配型号 + 用途；

4\. 规格数字标准化：2-проводный, 6 квадратных мм²;

5\. 适配设备/车型后置：... для Toyota Tundra、для пылесоса Youwang VC2303。

\## 模块3：两套标题固定模板

\### 精简标准版（短标题，搜索权重优先）

`Основной товар + ключевая характеристика`

示例: Потолочный вытяжной вентилятор со светодиодной подсветкой



\### 引流加长版（长标题，营销转化）

`Товар + материал + область применения + преимущества`

示例: Встроенный потолочный вытяжной вентилятор из гипсокартона, бесшумный, универсальный для кухни и ванной комнаты
